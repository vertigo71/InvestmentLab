# InvestmentLab

Investment strategy backtesting framework written in Python.

## Current Strategies

- All In
- Dollar Cost Averaging (DCA)
- Drawdown DCA

## Planned Features

- Rolling window analysis
- CAGR calculation
- Strategy comparison
- Money market benchmark
- Volatility-based contributions
